{% comment %} Server-rendered body for the "Delete token" confirmation modal. Only reached for an inactive token (revoked or deactivated); the view refuses an active one before this dialog is ever built. Deletion is permanent, so the wording says so and names the token. `token.source_token_count` is annotated by `_settings_sources_context`. When it is 1 this is the feed's last credential, so the delete also reaps the feed and its mapping profile — a consequence the operator must see *before* confirming, not discover afterwards. The feed's alerts are kept (the FK is SET_NULL), so the count only warns that they stop naming a feed. {% endcomment %}
