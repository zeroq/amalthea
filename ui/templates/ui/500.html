{% comment %} Server-error page (handler500). Deliberately standalone — it does **not** extend `base.html`. A 500 most often means the database (or a dependency) is unavailable, so this template must render without touching the DB. `base.html` reads `request.user` and `request.resolver_match` and loads the nav counts; `ui.views.handler500` therefore renders this file with `loader.render_to_string` (no request context processors), and this template references nothing request-scoped: no `{% url %}`, no `request`, no `messages`. Styling uses only component classes already emitted by `ui/static/ui/app.css` (`.card`, `.notfound`, `.notfound-code`, `.notfound-text`). No Tailwind utilities, because app.css is its own Tailwind input (no template rescan) and an unlisted utility would silently no-op. {% endcomment %} {% load static %} Server error · Amalthea
