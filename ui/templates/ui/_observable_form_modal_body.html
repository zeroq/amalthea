{% load ui_tags %} {% comment %} Body of the observable create/edit modal (`_modal.html` `body_template`). One template serves both paths: - Create: `observable` is not in context (or is None), fields are empty. - Edit: `observable` is in context, `is_edit=True` is passed; the form is prefilled. The modal footer owns the submit, so each control MUST carry `form="{{ form_id }}"` (`form_id` is set by `_modal.html`; see `_page_form.html` and the TTP fix in `_procedure_form_modal_body.html`). Without it the POST arrives with empty fields. IDs are prefixed with `modal_id` rather than hard-coded: create and every edit modal coexist in one document, so a shared id would give every label the wrong control. {% endcomment %}
