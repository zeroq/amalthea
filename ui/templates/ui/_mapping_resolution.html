Rendered next to the append-only `warnings` log because the two answer different questions and only the difference makes them readable: * this block describes the row **now** — fix the rule and re-apply, and the entry disappears; * the log is the row's **history** — the ingest-time `severity_defaulted: no severity mapping …` line stays forever, because it was true when it was written. Without this block the only visible line was that historical one, so a rule that resolved nothing looked exactly like a rule that worked.
