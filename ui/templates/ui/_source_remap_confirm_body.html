{% comment %} Body of the "Apply this mapping to existing alerts?" confirmation modal (P7, extended in P7.1). Server-rendered, and deliberately explicit about both halves of the operation: the mapping is saved *and* the alerts are rewritten, the candidate set is stated in numbers rather than as "some alerts", and what is left alone is spelled out — an operator cannot make an informed decision about a bulk write they cannot see the shape of. Since P7.1 the numbers come from a **dry pass over the real alerts**: per target what the mapping would change, and where it produced no value at all — the one thing "0 updated" cannot say, and the reason an operator whose severity rule is wrong otherwise ships a silent no-op. The dialog reuses `ui/_modal.html` (no new CSS class) and carries no inline script or style (ADR-003). {% endcomment %} {% load ui_tags %}
