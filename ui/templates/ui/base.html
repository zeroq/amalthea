{% load static %}{% comment %} Base layout for every analyst page. Structure is a fixed left rail plus a main column, which is what a keyboard-driven triage tool wants: the rail is in the same place on every screen, so `g` then `c` is a muscle memory rather than a hunt. No build step, no framework, no CDN — the whole UI is templates plus one stylesheet, because a SPM dependency here would cost more than it saves at MVP scale. Accessibility notes that are not optional: * the skip link is the first focusable element, so a keyboard user is not forced through the rail; * `:focus-visible` is styled, not removed — keyboard focus must always be visible; * severity is conveyed by label text as well as colour, never by colour alone (WCAG 1.4.1); * the live region announces Django messages so a redirect-after-POST is confirmed. {% endcomment %} {% block title %}Amalthea{% endblock %} Skip to main content
